# UI (`packages/ui`)

> Design system — design tokens, components, and primitives.

Canonical tokens live here as the single source of truth for both Flutter and web.
See the [Design System Specification](../../../../docs/specifications/DESIGN_SYSTEM.md)
and [ADR-0002: Flutter](../../../../docs/architecture/adrs/ADR-0002-flutter.md).

- Tokens: colors, spacing, typography, radii, motion, breakpoints.
- Icons: Material Icons (Flutter) + SVG set for web.
- One owner per component; changes are PR-reviewed.
